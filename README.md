Deskripsi

Praktikum ini membahas perbedaan antara pemrograman prosedural dan Object-Oriented Programming (OOP) menggunakan bahasa PHP.

Program menggunakan data 3 buku:

1. Laskar Pelangi - Andrea Hirata (2005)
2. Bumi - Tere Liye (2014)
3. Negeri 5 Menara - Ahmad Fuadi (2009)

Perbedaan Pemograman Prosedural dan OOP

1. Struktur Kode
   Pada pemograman prosedural, saya menggunakan array dan perulangan foreach untuk menampilkan data buku. Sedangkan pada OOP, saya menggunakan class Buku, constructor, dan method info().

2. Pengelolaan Data
   Pada pemograman prosedural, data buku disimpan dalam array dan diakses menggunakan indeks seperti$b['judul']. Sedangkan pada OOP, data disimpan sabagai properti objek dan diakses menggunakan '$this->judul'.

3. Kemudahan Pengembangan
   Menurut saya, pemrograman prosedural lebih mudah digunakann untuk program sederhana karena kodenya lebih singkat. Namun, OOP lebih tersturktur dan lebih mudah dikembangkan jika jumlah data atau fitur program bertambah.

Cara menjalankan program

Buka terminal pada folder proyek, kemudian jalankan:

php index.php

Kesimpulan
Dari praktikum ini, saya memahami bahwa pemograman prosedural berfokus pada langkah-langkah program, sedangkan OOP menggunakan class dan objek untuk mengelola data serta fungsi.

Kedua pendekatan menghasilkan output yang sama, tetapi memiliki struktur kode yang berbeda.
